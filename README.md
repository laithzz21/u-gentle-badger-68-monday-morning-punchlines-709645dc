A single joke about Monday mornings, under 200 characters, on one line.

## Entry

> Monday morning: my alarm rings, I hit snooze, and my bed whispers, 'Stay — work will still be miserable without you.'

## Run

```sh
python3 main.py
```

`main.py` prints exactly the entry text to stdout, with no extra output.
